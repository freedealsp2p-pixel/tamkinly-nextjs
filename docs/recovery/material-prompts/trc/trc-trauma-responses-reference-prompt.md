## 2. Purpose
A psychoeducation handout explaining the four trauma response patterns (fight, flight, freeze, fawn), their nervous system basis, and how to recognize them. From Framework Principle 5 and the interactive trauma-responses tool.

## 3. Target User
Survivors wanting to understand their body's response patterns. Useful for reducing self-blame ("why didn't I fight?").

## 4. When To Use
As introductory reading before exploring personal patterns. When confused by own responses. When reducing shame about "not fighting back."

## 5. When Not To Use
If reading about responses triggers acute distress → ground first. Not a substitute for professional trauma education.

## 6. Therapeutic Structure
Page 1: 4 response patterns with descriptions (fight, flight, freeze, fawn) + nervous system diagram (simplified) + "Why you responded this way" normalization
Page 2: Personal identification section + "My dominant pattern" + "What helps me when I'm in this response" + grounding reset + referral

## 7. User Interaction
User reads psychoeducation, identifies personal patterns, notes helpful strategies.

## 8. Examples
No examples needed — psychoeducation content.

## 9. Safety
General trauma warning. Grounding reset. Therapist referral. Normalize responses to reduce shame.
