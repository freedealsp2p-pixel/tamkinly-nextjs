## 2. Purpose
A quick-reference card summarizing all regulation tools available in Stage 2, their purpose, and when to use each. Companion to the regulation-toolkit interactive page.

## 3. Target User
Survivors in Regulation stage who need a quick reminder of available tools and their appropriate use.

## 4. When To Use
As daily reference. When choosing which tool to use for current distress. When building a personal regulation toolkit.

## 5. When Not To Use
Not a standalone therapeutic tool — reference only. Not for acute crisis (use safety plan instead).

## 6. Therapeutic Structure
Page 1: Summary table of all regulation tools (trigger mapping, safety plan, regulation toolkit, EFT, thought reframing, trauma journal, trauma responses, shame recovery) with columns: Tool, Purpose, When to Use, When NOT to Use, Duration
Page 2: Quick decision flowchart ("If feeling X → try Y first") + grounding reset + referral

## 7. User Interaction
User reads reference information to choose appropriate tool. No writing required (except emergency contacts).

## 8. Examples
No examples — this is a reference card.

## 9. Safety
General safety reminder. Therapist referral. Crisis redirect.
