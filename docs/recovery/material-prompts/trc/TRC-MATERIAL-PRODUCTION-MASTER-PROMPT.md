## 2. Safety Rules (Non-Negotiable)

### 2.1 Trauma Warning (Required on ALL therapeutic worksheets)
```
⚠️ تنبيه مهم / Important Notice
هذه الورقة تحتوي على أسئلة عن تجارب صادمة.
يمكنك التوقف في أي لحظة.
This worksheet contains questions about distressing experiences.
You can stop at any time.
```

### 2.2 Grounding Reset (Required at end of ALL therapeutic worksheets)
```
إعادة الارتكاز / Grounding Reset:
خذ نفسًا عميقًا. / Take a deep breath.
5 أشياء تراها: ____ ____ ____ ____ ____
4 أشياء تلمسها: ____ ____ ____ ____
3 أصوات تسمعها: ____ ____ ____
تذكّر: أنت الآن في أمان. / Remember: you are safe now.
```

### 2.3 Therapist Referral (Required on ALL therapeutic worksheets)
```
هذه الورقة أداة داعمة وليست بديلاً عن علاج متخصص.
This worksheet is a supportive tool, not a replacement for specialized treatment.
معالج/مركز صدمات: __________
Therapist/Trauma Center: __________
خط مساعدة وطني: __________
National Helpline: __________
```

### 2.4 Contraindications (From TRC Framework Section هـ)
- Self-harm/suicidal thoughts → emergency services immediately
- Frequent panic preventing sleep/work → trauma therapist referral
- Trigger Mapping: trauma < 2 weeks → breathing + grounding only
- EFT: dissociation unable to control → stop, redirect to therapist
- Recovery Journal: insufficient safety built → start with grounding
- Body Scan: not trained to return to present → start with A52 only

### 2.5 Dissociation Protocol (From Framework)
1. Stop content immediately
2. Apply 5-4-3-2-1 grounding
3. 3 deep breaths A52 pattern
4. If persists → redirect to emergency services

### 2.6 Clinical Review Requirement
- EFT materials MUST be marked clinical-review
- Trauma Journal materials MUST be marked clinical-review
- Safety Plan materials MAY be live (Stanley-Brown is evidence-based)
- All other materials MAY be live

## 3. Domain Isolation Rules (Absolute)

### TRC ≠ Porn Recovery
NEVER include in TRC materials:
- Urge Surfing techniques
- Relapse Analysis frameworks
- Porn Trigger Journal
- Porn Recovery Loop concepts
- Porn Identity Cards
- "Addiction" or "compulsive behavior" language
- HALT framework
- Any reference to `/downloads/porn-recovery/`

### Exception
Only if Source Material explicitly documents a concept as shared between both domains.
Name similarity alone is NOT sufficient.

## 4. Bilingual Rules (Mandatory)

Every material MUST be produced in both:
- **Arabic version** (primary, RTL)
- **English version** (equivalent, LTR)

### Equivalence Requirements:
- Same sections and structure
- Same exercises and prompts
- Same safety information
- Same writing space allocation
- Same practical value
- Same therapeutic depth
- NOT just literal translation — culturally appropriate phrasing
- Arabic uses formal/clinical register (not dialect)
- English uses clinical/accessible register

### File Naming:
- `TRC-[ASSET]-[TYPE]-AR.pdf`
- `TRC-[ASSET]-[TYPE]-EN.pdf`

Example:
- `TRC-TRIGGER-MAPPING-WORKSHEET-AR.pdf`
- `TRC-TRIGGER-MAPPING-WORKSHEET-EN.pdf`

## 5. Worksheet Rules (From Template)

### Structure (Mandatory Order):
1. Trauma Warning (except Parents Guide)
2. Header (Title AR + EN, description)
3. Date/Time fields
4. Purpose section
5. When To Use section
6. Safety Instructions
7. Fields (user interaction areas)
8. Grounding Reset
9. Therapist Referral

### Field Types Allowed:
| Type | Symbol | Use | Example |
|------|--------|-----|---------|
| Wide text | 3-6 lines | Therapeutic writing | "What was hardest this week?" |
| SUDS Scale | 0-10 | Distress measurement | Before/after EFT |
| Checkbox | ☐ | Multiple choice | Early warning signs |
| Simple table | Columns + rows | Tracking | Date/Trigger/Response |
| Text box | Large area | Alternative thoughts | Thought-Evidence-Alternative table |

### Field Differences from Porn Recovery:
- TRC: wide text areas, free writing, SUDS 0-10, "what does my body need?"
- NOT: dense checkboxes, urge tracking, "what did I learn?", commitment signatures

## 6. Visual Rules

### Style: Clinical / Calm / Practical / Trustworthy

**Colors:**
- Primary: #1F6F78 (teal — TRC brand)
- Secondary: #0F1C2E (dark navy)
- Accent: #3DD4B0 (light teal)
- Warning: amber/red for safety notices
- Background: white/cream
- Text: dark gray/navy

**Allowed Visual Elements:**
- Nervous system diagrams (simple, anatomical)
- Body awareness illustrations (outline, not photographic)
- Simple anatomical/physiological visuals
- Trauma response diagrams (fight/flight/freeze/fawn)
- Structured therapeutic layouts
- Tapping point diagrams (for EFT)
- Breathing pattern visualizations

**Forbidden Visual Elements:**
- Meditation stock imagery
- Spiritual imagery (chakras, energy fields)
- Generic wellness photography
- Decorative imagery without function
- Photos of people in exaggerated emotional states
- Nature scenes used as decoration only
- Any imagery that could trigger trauma responses

**Typography:**
- Arabic: Cairo or Noto Sans Arabic
- English: Inter or Noto Sans
- Headers: Bold, larger size
- Body: Regular weight, readable size (11-12pt)

**Layout:**
- A4 format
- Clear margins (2cm minimum)
- Consistent spacing
- Page numbers on multi-page documents
- TRC branding element (small, footer area)

## 7. No-Prefill Rules (Critical)

ALL user fields MUST be blank and ready for user input.

**Forbidden pre-filling:**
- Emotions (e.g., "fear", "shame")
- Triggers (e.g., "crowds", "certain smells")
- Ratings (e.g., pre-set SUDS values)
- Goals (e.g., "feel safe in crowds")
- Reflections (e.g., "I learned that...")
- Answers (e.g., "the alternative thought is...")
- Recovery plans
- Personal examples inside user fields

**Allowed examples:**
- In a clearly demarcated section titled **"Example / مثال"**
- Visually separated from user writing space (different background color, border)
- Labelled explicitly as an example
- Never mixing with user's actual workspace

## 8. Evidence Rules

**Code does not create methodology. Source does.**

- If Source Material supports a claim → include with attribution
- If Framework supports a claim → include with reference
- If neither supports → DO NOT include
- Never present EFT as evidence-based PTSD treatment
- Never present SUDS as clinical assessment (it's self-awareness only)
- Never include success rates or effectiveness claims without citation
- Never use "proven", "cure", "treatment" for non-clinical tools
- Always frame self-help tools as "supportive, not replacement for therapy"

- PDF, A4 (210 × 297 mm)

