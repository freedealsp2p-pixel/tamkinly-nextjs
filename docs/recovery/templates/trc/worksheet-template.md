## بنية ورقة العمل TRC

كل ورقة عمل في مسار TRC يجب أن تتبع هذه البنية:

### ۱. رأس الأمان (Safety Header) — إلزامي

```
⚠️ تذكير: هذه الورقة أداة دعم ذاتي، وليست بديلاً عن العلاج المتخصص.
إذا شعرت بأي من التالي أثناء العمل على هذه الورقة، توقف فورًا:
- صعوبة شديدة في التنفس
- شعور بالانفصال عن جسدك
- ذكريات مؤلمة لا يمكنك السيطرة عليها
→ استخدم تقنية 5-4-3-2-1 أو تنفس A52 (5-5-2)
→ إذا استمرت، تواصل مع خدمات الطوارئ المحلية.
```

### ۲. عنوان واضح + وصف مختصر
- العنوان بالعربية والإنجليزية.
- سطر واحد يشرح الهدف: "استخدم هذه الورقة لـ..."

### ۳. متى تُستخدم / متى لا تُستخدم
- **تُستخدم عندما:** حالات مناسبة.
- **لا تُستخدم عندما:** موانع الاستخدام (من trc-framework.md القسم هـ).

### ٤. تعليمات واضحة خطوة بخطوة
- كل خطوة مرقّمة.
- لغة بسيطة ومُهَدِّئة.
- لا ضغط للإكمال.

### ٥. حقول التعبئة
- حقول نصية مع خطوط نقطية.
- مربعات اختيار (checkboxes) عند الحاجة.
- مقاييس (1-10) عند الحاجة.

### ٦. تأمين الارتكاز (Grounding Anchor) — إلزامي بين الأقسام
```
→ توقف لحظة. خذ نفسًا عميقًا.
→ انظر حولك: ۳ أشياء تراها، ۲ تلمسها، ۱ تسمعه.
→ هل أنت مستمر بالراحة؟
```

### ۷. ختام تثبيتي (Closure)
- تمرين تنفس (A52 أو Box Breathing).
- رسالة تمكين من المادة العلمية.
- "ما الذي ستفعله لنفسك اليوم؟"

### ۸. مراجع وموارد
- رابط العودة لصفحة TRC الرئيسية.
- أرقام الطوارئ المحلية.
