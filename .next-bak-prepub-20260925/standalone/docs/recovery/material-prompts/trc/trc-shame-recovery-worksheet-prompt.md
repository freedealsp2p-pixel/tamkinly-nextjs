## 2. Purpose
A TF-CBT based worksheet for identifying shame messages, understanding their origin, distinguishing facts from learned beliefs, and developing compassionate alternatives. From Framework Principle 7 (rebuilding self-narrative).

## 3. Target User
Survivors carrying shame-based beliefs: "It was my fault", "My body is dirty", "I should have stopped it".

## 4. When To Use
After thought-reframing prerequisite. When specific shame messages are identified as maintaining trauma. In calm moments.

## 5. When Not To Use
Acute crisis. Severe dissociation. If shame is so overwhelming that examining it causes flooding → ground first.

## 6. Therapeutic Structure
Page 1: Trauma warning + identify shame message + origin (self/others/culture/experience) + fact or learned belief?
Page 2: compassionate response + truth statement + daily affirmation practice area
Page 3: Practice table + grounding reset + referral

## 7. User Interaction
User identifies shame message, traces origin, evaluates fact vs learned, writes compassionate alternative, practices daily.

## 8. Examples
Example: Shame message: "My body is dirty." Origin: Culture/Religion. Fact or learned: Learned. Compassionate response: "My body is my home. What happened does not define my body's worth."

## 9. Safety
Trauma warning, grounding reset, therapist referral. Shame can be deeply triggering — stop if flooding occurs.
