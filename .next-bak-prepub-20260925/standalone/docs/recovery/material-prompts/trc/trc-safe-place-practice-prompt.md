## 2. Purpose
A guided practice sheet for developing and strengthening the internal "safe place" visualization. Companion to the safe-place interactive tool. From Framework Stage 1: building internal safe place is a core safety skill.

## 3. Target User
Survivors ready to develop an internal sanctuary they can return to during distress. Must have basic grounding skills first.

## 4. When To Use
- During calm moments to build the visualization
- Before distress increases as preventive practice
- After grounding when still unsettled but not in acute crisis
- Before sleep to reduce nightmares

## 5. When Not To Use
From Framework: severe dissociation, active flashbacks, claustrophobia (if imagining enclosed space). If visualization increases distress → switch to sensory grounding.

## 6. Therapeutic Structure
Page 1: Trauma warning + guided questions for building safe place (What do you see? Hear? Smell? Feel? Who is there? What makes it safe?) + sensory details recording
Page 2: Practice log (date, duration, SUDS before/after, what helped) + "returning to safe place" quick-access script + grounding reset + referral

## 7. User Interaction
User describes their safe place in sensory detail, records practice sessions, notes effectiveness.

## 8. Examples
Example box: "My safe place is a beach at sunrise. I hear waves, smell salt air, feel warm sand. Nobody can reach me here without my permission."

## 9. Safety
Trauma warning, grounding reset, therapist referral. Dissociation protocol: if visualization triggers flashback → open eyes, ground, stop.
