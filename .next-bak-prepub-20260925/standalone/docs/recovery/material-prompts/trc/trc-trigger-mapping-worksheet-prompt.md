## 2. Purpose

A structured worksheet for identifying personal trauma triggers, understanding the body's response patterns, and developing coping strategies. From TRC Framework Worksheet 1 and Download Prompt 1. This is P0 because it's the first Regulation-stage exercise and essential for journey continuity.

## 3. Target User

Survivors who have completed Safety stage and are ready to:
- Understand their personal trigger patterns
- Map trigger-response connections
- Develop personalized coping plans

## 4. When To Use

From Framework Section هـ:
- After completing Safety stage (grounding + breathing established)
- NOT if trauma occurred less than 2 weeks ago (need stabilization first)
- When feeling stable enough to explore triggers without overwhelming distress
- In a safe, calm environment

## 5. When Not To Use

- Trauma < 2 weeks → use breathing + grounding only
- Currently in acute crisis → use safety plan first
- Severe dissociation → ground first, do not explore triggers
- Unable to return to present after thinking about triggers → stop

## 7. User Interaction

The user:
- Describes the triggering situation
- Identifies body sensations (checkboxes + custom)
- Locates sensations in body
- Identifies automatic thoughts (checkboxes + custom)
- Describes coping used
- Evaluates what helped/didn't help
- Plans alternative coping for next time
- Tracks multiple triggers in table format

Example in separate box:
