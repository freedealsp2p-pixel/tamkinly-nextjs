# TRC Material Priority Classification
# تصنيف أولويات المواد العملية TRC

**Date:** 2026-08-12

---

## P0 — Essential for Journey Continuity or Safety

These materials MUST exist for the therapeutic journey to function safely. Without them, users hit gaps at critical safety points.

| ID | Material | Reason | Consequence if Missing |
|----|----------|--------|----------------------|
| M-01 | Grounding Pocket Card | Emergency offline access to 5-4-3-2-1 | Users cannot ground without app |
| M-02 | A52 Breathing Practice Card | Daily regulation and acute stress reference | Users forget breathing patterns without guide |
| M-05 | Emotional Safety Plan | Crisis protocol (Stanley-Brown) | No concrete crisis plan when digital access unavailable |
| M-07 | Trauma Trigger Identification Worksheet | First Regulation exercise | Journey dead-end at Regulation entry |

**All 4 have existing AR PDFs but NO EN counterparts. EN production is the immediate priority.**

---

These materials extend the interactive tools with offline/companion resources. The journey functions without them, but their absence reduces practical therapeutic value.

| ID | Material | Extends Tool | Value Added |

| M-03 | Safe Place Practice Sheet | safe-place | Guided visualization practice offline |
| M-04 | Body Awareness Worksheet | body-scan | Body tension mapping offline |
| M-08 | Regulation Quick Reference | regulation-toolkit | Quick tool selection reference |
| M-09 | Trauma Response Patterns Ref | trauma-responses | Psychoeducation handout |
| M-10 | Thought Reframing Worksheet | thought-reframing | CBT exercise offline |
| M-11 | Shame Recovery Worksheet | shame-recovery | TF-CBT shame work offline |
| M-12 | Trauma Recovery Journal Guide | trauma-journal | Structured writing with safety |
| M-13 | EFT Self-Help Worksheet | eft-tapping | Tapping point reference + log |
| M-18 | Breathing Techniques Guide | a52-breathing | Combined 4-pattern guide |

**8 of 9 have existing AR PDFs but NO EN counterparts. 1 (M-18) needs both AR+EN.**
