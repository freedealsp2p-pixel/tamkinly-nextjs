## Architecture Overview

TRC (Trauma Recovery from Sexual Harassment) follows a 3-stage sequential model.
Each stage has Therapeutic Tools, Articles, and Downloads.
All TRC assets use `sectionType: 'therapeutic'` and require TherapeuticExit.
