## 2. Purpose
A CBT-based worksheet for identifying distorted thoughts related to trauma and developing evidence-based alternatives. From Framework Worksheet 7 (Thought-Evidence-Alternative) and Principle 7 (rebuilding self-narrative via TF-CBT).

## 3. Target User
Survivors experiencing trauma-related cognitive distortions: self-blame, shame beliefs, catastrophic thinking, overgeneralization.

## 4. When To Use
After Safety stage completion, when experiencing specific distressing thoughts that maintain trauma responses. In calm moments to prepare for challenging situations.

## 5. When Not To Use
Acute crisis, active psychosis, severe dissociation preventing cognitive engagement. If examining thoughts increases distress beyond manageable → stop and ground.

## 6. Therapeutic Structure
Page 1: Trauma warning + identify the thought + identify associated emotion + rate intensity (SUDS)
Page 2: Evidence FOR the thought + Evidence AGAINST the thought (two-column) + compassionate alternative + rate new intensity
Page 3: Practice table for multiple thoughts + grounding reset + referral

## 7. User Interaction
User writes original thought, identifies emotion, lists evidence for/against, writes compassionate alternative, compares intensity before/after.

## 8. Examples
Example box: Original: "It was my fault." Evidence for: "I didn't fight back." Evidence against: "I was a child. The perpetrator had power." Alternative: "I survived. Not fighting was a survival response, not consent."

## 9. Safety
Trauma warning, grounding reset, therapist referral. Cognitive overload warning: if examining evidence is too distressing → stop and ground.
