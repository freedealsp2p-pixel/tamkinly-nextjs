## 2. Purpose
A structured journaling guide with safety protocols and guided prompts for processing traumatic experiences. From Framework Worksheet 4 and Download Prompt 4. CLINICAL-REVIEW: contains therapeutic writing intervention.

## 3. Target User
Survivors with established safety skills who are ready for structured expressive writing. Must have grounding and breathing as fallback.

## 4. When To Use
After Safety stage completion, during calm moments, as regular practice (weekly), with sufficient time to complete grounding reset after writing.

## 5. When To Use
From Framework: NOT if insufficient safety built → start with grounding. Writing about trauma details can activate memories — safety protocols are mandatory.

## 6. Therapeutic Structure
Page 1: Trauma warning + journaling safety rules (time-limit, stop-if-distressed, grounding-after) + week/dates header
Page 2: 5 guided prompts with wide writing spaces (from Download Prompt 4: hardest thing, small pride, body tension, needed words, one safe action)
Page 3: Optional: additional reflection + grounding reset + referral

## 7. User Interaction
User writes in response to guided prompts, follows time-limiting, completes grounding reset after each session.

## 8. Examples
Example box: Prompt "What was hardest this week?" → Example response: "Nightmares returned after the work event. I used A52 breathing and it helped after 5 minutes."

## 9. Safety
CLINICAL-REVIEW. Trauma warning. Time-limiting guidance. Mandatory grounding reset. Therapist referral. Journaling safety: don't write details you're not ready for, stop if distress increases.

## 10. Layout
3 pages A4. Guided prompts. Wide writing spaces. Time/safety tracking.

## 11. AR/EN Requirements
Same 5 prompts, same safety rules, same grounding reset.
