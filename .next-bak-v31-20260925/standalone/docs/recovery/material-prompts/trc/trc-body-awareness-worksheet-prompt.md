## 2. Purpose
A companion worksheet for the Body Scan interactive tool. Guides the user to map where they hold tension in their body, understand trauma-body connections, and track body awareness over time. From Framework Principle 2 (trauma is stored in the body).

## 3. Target User
Survivors learning to notice body sensations and reconnect with their physical self after dissociation or disconnection.

## 4. When To Use
- After practicing grounding and breathing (Safety stage prerequisite)
- As companion to the body-scan interactive exercise
- When experiencing physical symptoms without clear cause
- Not if severe dissociation prevents body awareness → start with grounding

## 5. When Not To Use
From Framework Section هـ: Body Scan contraindicated if person hasn't learned to return to present → start with A52 only. Also: recent physical/sexual trauma, severe chronic pain, body dysmorphia.

## 6. Therapeutic Structure
Page 1: Trauma warning + body outline diagram for mapping tension areas
Page 2: Body region checklist (head, neck, shoulders, chest, stomach, lower back, hips, legs) with sensation options (tension, numbness, pain, warmth, heaviness) + free writing
Page 3: "What does my body need right now?" section + weekly tracking table + grounding reset + referral

## 7. User Interaction
User maps tension on body outline, checks body regions and sensations, writes what body needs, tracks weekly changes.

## 8. Examples
Example box: "I notice tension in my shoulders and heaviness in my chest. My body needs gentle stretching and slow breathing." (Clearly separated from user space.)

## 9. Safety
Trauma warning, dissociation protocol (stop if disconnected), grounding reset, therapist referral. From Framework Principle 2.

## 10. Layout
3 pages A4. Body outline diagram. Region checklists. Wide writing spaces.
