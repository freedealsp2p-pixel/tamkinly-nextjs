## مقدمة

هذا المستند يربط **مصنع التنزيلات (Download Factory)** بالأصول الفعلية في منصة تمكينلي. يُحدِّد لكل أصل ما يُنزَّله المستخدم، ونوع القالب، وفئة التنزيل، والأولوية، وحالة البناء.

## تعريف أنواع القوالب

| نوع القالب | الوصف | المواصفات |
|---|---|---|
| **pdf-card** | بطاقة PDF مُصغَّرة قابلة للطباعة والاحتفاظ بها في المحفظة أو الجيب. تُلخّص الخطوات الأساسية للتمرين. | حجم A6 أو بطاقة crédit card، وجه واحد أو وجهان، خطوط كبيرة واضحة، ألوان مهدئة، رموز بصرية. |
| **pdf-worksheet** | ورقة عمل PDF تفاعلية يملأها المستخدم يدوياً بعد الطباعة. تحتوي على حقول مُهيكلة وأسئلة مُوجَّهة. | حجم A4، حقول مُهيكلة مع عناوين، مساحة للكتابة، تعليمات واضحة، رابط QR للعودة للمنصة. |
| **pdf-article** | مقال تثقيفي بصيغة PDF مُنسَّق للقراءة أو الطباعة. يحتوي على محتوى علمي مبسّط مع رسوم توضيحية. | حجم A4، أعمدة مُنسَّقة، تحذير محتوى في الأعلى، روابط للأدوات التفاعلية، مراجع علمية. |

## العلاقة مع مصنع برومبتات الإنتاج

> **المرجع:** `/var/www/tamkinly/docs/recovery/downloadable-asset-prompts.md`

مكتبة برومبتات الإنتاج تحتوي على 6 برومبتات قابلة لإعادة الاستخدام. كل تنزيل يستخدم برومبتاً محدداً:

| البرومبت | الاستخدام | التنزيلات المرتبطة |
|---|---|---|
| Prompt 01 — Worksheet | أوراق العمل المُهيكلة | safe-place-worksheet, body-awareness-worksheet |
| Prompt 02 — Guided Exercise PDF | أدلة التمارين والبطاقات | a52-breathing-card, grounding-pocket-card |
| Prompt 03 — Psychoeducation Guide | المقالات التثقيفية | psychoeducation-pdf |
| Prompt 04 — Recovery Workbook | الكُتيّبات الشاملة | — (مستقبلاً) |
| Prompt 05 — Crisis/Safety Resource | موارد الأزمات | — (مستقبلاً) |
| Prompt 06 — Checklist | قوائم التدقيق | — (مستقبلاً) |

## سير عمل الإنتاج

```
1. تحديد التنزيل ← هذا المستند (خارطة الطريق)
2. اختيار البرومبت ← مكتبة برومبتات الإنتاج
3. جمع متغيرات الإنتاج ← من السجل + المواصفة السريرية
4. توليد المحتوى ← LLM + مراجعة سريرية
5. تصميم PDF ← القالب المرئي (Template)
6. مراجعة الجودة ← قائمة مراجعة الجودة في مكتبة البرومبتات
7. التدقيق السريري ← فريق التدقيق السريري
8. النشر ← ربط بالأصل في السجل
9. تحديث الحالة ← من `planned` إلى `built`
```
